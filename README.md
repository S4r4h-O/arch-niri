# Arch-Niri

My minimal Arch installation with the [Niri WM](https://github.com/niri-wm/niri).

Easy pre-install with archinstall:

```bash
archinstall --config-url https://codeberg.org/saaaraaah/arch-niri/raw/branch/main/user_configuration.json
```
